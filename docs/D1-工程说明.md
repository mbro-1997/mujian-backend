# D1 工程说明与复核入口

2026-10-23；待总工程师复核。唯一接口契约：[OpenAPI](../../../开发交接/D1-最小框架/契约/C-D1基础接口.openapi.json)。

## 请求路径

ApiBoundaryFilter（方法/输入/trace/no-store/错误）→ Spring Security IdentityFilter 与 CsrfFilter → Controller → ApplicationService → MyBatis Mapper/XML。请求、持久化与响应类型分离；SQL 显式列名。权限每请求从 MySQL 批量读取 4 次并复用，不把角色和菜单快照放入 Redis。

8 个操作：管理 csrf、login、me、menus、system/menus、logout；小程序 me/context、logout。管理员 Cookie 与小程序 Bearer 使用 clientType 隔离；请求头 X-Session-Activity 只有 interactive/background，后端成功的受保护 GET 才承认有效活动。

## 会话保存边界

使用官方 RedisIndexedSessionRepository 保存会话及索引；为了防止迟到保存复活，关闭自动 Servlet Session Filter。新会话只在凭据发布前调用一次官方 save；已发布会话不再调用 save。所有应用活动通过原子 Lua 检查存活、先判过期，再单调推进 lastInteractiveAt/TTL；退出先标记失效再经官方删除与 hash 删除。不能绕过 SessionService 直接保存旧 Session 对象。

存储仅含 userId、clientType、认证/活动时间、CSRF 及框架索引/时间属性。hash 的 d1:active/d1:last/d1:limit 是原子失效与期限判定所需元数据，不含业务权限。Spring Security CsrfFilter 与框架掩码处理器执行 CSRF 验证；不自写 token 相等比较。

管理端闲置 4 小时、小程序 30 天；持续有效活动无绝对截止。匿名 CSRF 会话 10 分钟。后台读取不保存或续期；Lua touch 不创建不存在的 hash。数据序列化采用受限白名单，生产 Redis 必须独立部署、认证并限制网络访问；本轮只验证 loopback 本机实例。测试用 Clock 推进正式期限，不修改期限参数。

MySQL 与 Redis 不在同一个分布式事务内：认证通过后更新 last_login_at，若 Redis 保存失败返回 503，可能已更新时间；不能将该时间视为会话建立成功。网络超时也是未知结果，管理端查询 me 确认，不自动重放命令。

## 迁移与工具边界

V1 建 7 表/60 字段/41 CHECK/10 RESTRICT 外键/8 非主键唯一索引；V2 只插固定种子。普通运行无 DDL；独立迁移账号无 DROP。Flyway cleanDisabled，DDL 失败必须诊断并前向修复。sys_user 系统身份被修改时启动检查失败，不自动修复用户数据。

MiniSessionCli 仅在 src/test，生产 jar 不包含。显式本机 development/test 配置才运行；输出权限 600 的随机会话文件，不打印 token，无 HTTP 注入路由。它创建的是测试身份，不代表手机号或微信注册规则改变。

## 已知限制

- 登录限流按账号/IP 记录 15 分钟内 5 次失败，成功只清账号。检查与失败计数是两个步骤：并发在途请求可越过阈值后完成；尚未做严格并发预约门禁。单次请求及 HTTP 429 已验证，总工程师应评估是否需在 D1 收紧。
- 单机测试只证明功能与约束；不承诺线上吞吐、集群容错、跨 Redis 节点事务或网关可信代理配置。
- 集成测试对代表性错误及所有成功操作有真实响应；未穷举每个操作的全部错误组合，机器契约静态反例不等于运行覆盖。
- 日志为结构化 key=value，只含固定路由、状态、耗时、trace。无密码、Cookie、Bearer、CSRF；没有为了日志建立业务审计表。

### 业务SQL统一使用Mapper.xml（2026-11-03用户确认）

- 后端业务SQL统一放在`src/main/resources/mapper/`对应领域XML中；Mapper.java仅保留方法声明及必要的`@Mapper`、`@Param`、映射标识等注解。禁止`@Select/@Insert/@Update/@Delete`、SQL Provider、Java字符串拼接或JdbcTemplate等作为业务SQL绕行入口。
- 接口入参显式`@Param`（无参方法除外），XML参数名、namespace、方法id、resultMap/resultType、生成主键及加载路径必须对应。已有XML继续复用；动态条件/列表/排序用XML及受控固定分支，不把外部值改成`${}`拼接。
- 迁移仅改变SQL存放与必要的映射适配；保持SQL语义、绑定、返回类型/空值/别名、动态条件、事务、锁、分页、更新行数和生成主键一致。业务问题单独登记，不夹带修改。JDBC转MyBatis需明确原RowMapper/Map值类型、零行行为与新结果映射的等价关系。
- 数据库迁移DDL、隔离测试夹具和非业务数据库启动检查分别登记，不因本规则机械迁入业务Mapper；不得借此例外在业务Java中保留SQL。废弃Provider/SQL工具仅在引用核对后移除。
- 只运行必要构建、映射加载/statement唯一检查及受影响数据库集成验证；未受影响通过证据复用，不重跑全量验收。不提交、推送或发布。
